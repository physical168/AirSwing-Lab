# AirSwing Bridge

This iPad Swift Playgrounds app reads 13 AirPods motion values and injects
them into the AirSwing dashboard. Computer mode is the default for fast web
updates, with a bundled offline dashboard as a fallback.

## Open on iPad

1. Download AirSwingBridge.swiftpm.zip from the GitHub repository.
2. Open the download in the Files app and tap it once to extract it.
3. Tap AirSwingBridge.swiftpm, then choose Swift Playgrounds.
4. Connect compatible AirPods and allow Motion and Local Network access.
5. Keep the PC dashboard server running and tap Start Sensor.

Use the gear button to switch between Computer and Offline modes.
