# AirSwing Bridge

This is an iPad Swift Playgrounds app that reads AirPods motion data and
injects it into the AirSwing web dashboard.

## Open on iPad

1. Download AirSwingBridge.swiftpm.zip from the GitHub repository.
2. Open the download in the Files app and tap it once to extract it.
3. Tap AirSwingBridge.swiftpm, then choose Swift Playgrounds.
4. Connect compatible AirPods and allow Motion and Local Network access.
5. Keep the PC dashboard server running, then tap Start Sensor.

The default dashboard is http://192.168.0.105:8001/. Use the gear button in
the app to change it when the PC address or port changes.
