# AirSwing Bridge

This is a fully offline iPad Swift Playgrounds app. It reads AirPods motion
data and injects it into the bundled AirSwing dashboard.

## Open on iPad

1. Download AirSwingBridge.swiftpm.zip from the GitHub repository.
2. Open the download in the Files app and tap it once to extract it.
3. Tap AirSwingBridge.swiftpm, then choose Swift Playgrounds.
4. Connect compatible AirPods and allow Motion access.
5. Tap Start Sensor. No PC, server, Wi-Fi or internet connection is required.

Calibration, angle analysis, charts and saved sessions all run on the iPad.
